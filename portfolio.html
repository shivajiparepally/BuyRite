Portfolio / demo project. Pay-at-pickup only — no live payment processing. Must be 21+ to purchase alcohol.

What's inside

Everything a small liquor store needs to take orders online and manage them from one dashboard.

🛒

Catalog & Search

Categories, per-size product variants, live search with autosuggest, and category filtering.

📦

Pay-at-Pickup Orders

Cart → order submission with live store-hours checks, next-day scheduling, and out-of-stock substitution rules enforced server-side.

🔐

Verified Accounts

Age verification (21+) at signup, email OTP verification, and OTP-gated password/username/email changes.

📊

Admin Dashboard

Orders with full status flow, cancel/archive/restore, product CRUD with image uploads, promotions, and store hours — all in one place.

🔔

Live Order Alerts

Sound + visual banner in the admin dashboard when a new order comes in, via polling.

🏷️

Promotions & Deals

Homepage carousel banners tied to categories or specific products, plus an always-on "On Sale" rail.

Built with

Django Django REST Framework PostgreSQL Simple JWT React Vite Tailwind CSS Docker Compose

Get it running locally

Full instructions are in the README — the short version:

Backend

cd backend → create a venv, pip install -r requirements.txt, set up .env, then python manage.py migrate && runserver.

Frontend

cd frontend → npm install → npm run dev, pointed at your backend via VITE_API_URL.

Or all at once

docker compose up --build spins up Postgres, the backend, and the frontend together.
